# RAG 05 — Agentic RAG Patterns

Covers the evolution from single-shot retrieval to multi-step agentic retrieval: Hypothetical Document Embeddings (HyDE), query decomposition for compound questions, Self-RAG (retrieval-triggered by model), Corrective RAG (quality classifier and web fallback), iterative retrieval loops, query routing across multiple indexes, and tool-using RAG combining retrieval with code execution and web search.
